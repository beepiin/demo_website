# demo_website

A static, single-page professional portfolio site for CA. Bipin Sharma, modeled after the reference website and built with HTML, CSS, and vanilla JavaScript.

## Run locally

```bash
python -m http.server 8000
```

Then open http://localhost:8000 in a browser.

## Project structure

- `index.html` — professional one-page layout and content
- `css/style.css` — custom styling and responsive layout
- `js/script.js` — mobile menu behavior
